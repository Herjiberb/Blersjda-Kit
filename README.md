Blersjda Kit is a party game collection for young ones, old ones, families, and fun times! Play games like Madness, Cap, Burn, and Strokes!
Madness: Make the funniest responses and get points. Rounds multiply points!
Cap: Like Madness, but you get to caption ridiculous, uncanny AI images!
Burn: Answer a simple prompt, make new prompts, and find the best combinations!
Strokes: Draw and create captions, and assemble the ultimate meme for the bracket!
